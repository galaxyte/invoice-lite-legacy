# InvoiceLite

A lightweight invoicing API for freelancers and small studios.

## Features

- Create, list, and fetch invoices via a simple REST API
- **PDF export** of any invoice, ready to email a client
- **Automatic email delivery** on invoice creation
- Multi-currency support (USD, EUR, GBP)
- Stripe payment link generation built in

## Quickstart

```bash
pip install -r requirements.txt
python app.py
```

## Running tests

```bash
pytest
```
